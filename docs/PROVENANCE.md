# Provenance and revision hierarchy

Prepared 2026-10-05 from the current conversation's available workspace. Current app source matches the privately published preview after the full-screen layout fix. This is a portable snapshot, not a hosting backup.

- proportions-and-linear-extensions-draft.pdf and proportions-and-linear-extensions.pdf: earlier rectangle series.
- rectangle-to-line-combined.pdf: earlier combined material before subsequent removals and measurement normalization.
- rectangle-to-line-revised.pdf: measured A4 master, nine principal examples plus rectangle pages; old family numbering.
- stimuli-2afc-review.pdf: selected 8 families, 18 unique pairs, with 2 overview pages. Source of the non-control SVGs. Its metadata and spacing predate the compact web fix.
- Current web app: adds the plain-line control (19 total), card calibration, 1 mm verification, current 220 × 120 mm layout and full-screen handling fix.

Earlier requested figure removals (2.02–7.02), text changes, rectangle relocation, snake tongue removal, train correction and family regrouping are represented across these versions. Current app selection supersedes historical PDF text/numbering. The pentagon and rectangle series are not in the current selected trials.

Included renders are for visual review only; vector files and numeric dimensions are authoritative. Runtime choices/responses were not persisted and are not included. No Optima font binary was available. The original screenshot used to request the very first rectangle series is not available as a source file here; its generated outputs are included.

Credit-card size reference used: ISO/IEC 7810 ID-1 nominal 85.60 × 53.98 mm, https://www.iso.org/standard/31432.html .
